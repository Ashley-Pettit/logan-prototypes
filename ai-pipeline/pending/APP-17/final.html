    How it works. Pick an approved template and a project, or add your own project data by pasting fields from an export. The page fills every field it can from the project data and shows where each value came from. AI writes only the free-text sections the template leaves open, using the project's notes. You check each drafted section, fix any missing data, then copy the finished document or download it as a Word file. Nothing is sent or saved without you.
