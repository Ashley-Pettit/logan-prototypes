    How it works. The dashboard shows each branch's plan status, when it was last tested and whether it is activated. Change a status with a reason and it goes in the activation log; an activated plan shows the time left before its most urgent critical function passes its maximum acceptable outage, with the plan's workaround. Pick a branch to build a desktop exercise: AI writes a realistic scenario with timed injects tied to that branch's critical functions. Run it with the team, record what happened against each inject, then let AI draft the evidence report and improvement actions. Saving it updates the evidence register and the branch's last tested date.
