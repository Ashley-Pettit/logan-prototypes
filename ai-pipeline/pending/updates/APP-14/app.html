    AI is off, so you see the clause by clause changes without a plain-English explanation.

    How it works. The page searches every clause in the library and ranks the best matches for your words. AI then writes a short plain-English answer from only those clauses, with clause references you can open. Road assets looks up a road in a sample asset register and checks its recorded widths, lighting, drainage and devices against the current clauses using fixed rules; name a road in a question and the answer covers that road too. Compare versions lines up clauses by number, marks what was added, removed or changed word by word, and AI explains what the changes mean for designers and assessors. Without AI, search, road checks and compare still work.
    Prototype handover notes
    • In the LCC stack for production: HTML, CSS and JavaScript front end (move to Vue and Bootstrap), Azure Function App for search and model calls, Blob Storage for documents, SQL or Cosmos DB for the clause index and version history, SharePoint or the document system as the source.
    • Needs an ICT-DA exception: Claude (Anthropic) as the AI provider, through the council's enterprise agreement. Third-party standards (for example state or Austroads documents) need licence checks before they are indexed.
    • Road assets: production reads the council's road asset register through an integration (Boomi or Logic Apps). The check rules that tie each asset field to a clause must be agreed with each standard's owner.
    • Privacy: only the question (with names, phone numbers and emails swapped for placeholders), the matched clauses and any named road's asset record are sent to AI. Documents are public or internal technical content with no personal information.
    • Every document, clause and number in this demo is made up. Real content must come from the approved, current council and state documents, with owners named for each.
    • Still needed for production: document owners and a version control process, a test plan with an AI evaluation set of questions with known answers, Dev, Test and Prod environments, and ICT-DA, CAB and business owner approvals.
