Rapid AI prototypeSample data only. Vehicles, jobs, procedures and specs are made up for this demo and are not from real manufacturer manuals. Always check the official manual before you work.

Workshop jobs

Sample work orders, made up for this demo. Pick one to ask about that vehicle.

    How it works. The page searches the workshop library for the sections that best match your question and the vehicle you picked. AI then writes a short answer using only those sections, with numbered sources you can open. If the library does not cover it, the answer says so and you can flag the gap for the knowledge owner. Without AI, you still get the best matching sections.
    Prototype handover notes
    • In the LCC stack for production: HTML, CSS and JavaScript front end (move to Vue and Bootstrap), Azure Function App for search and model calls, Blob Storage for manuals, SQL for fleet and job data from the fleet system.
    • Needs an ICT-DA exception: Claude (Anthropic) as the AI provider, through the council's enterprise agreement. Manufacturer manuals may also need licence checks before they are loaded.
    • Privacy: only the question, vehicle model and the matched library sections are sent to AI. Driver names and any staff details stay out. Fleet numbers are asset IDs, not personal data.
    • Every specification in this demo is made up. Real torque values, capacities and fault codes must come from the official manuals and approved City Fleet procedures.
    • Still needed for production: real manual set and procedure owners, a test plan with an AI evaluation set (questions with known answers), Dev, Test and Prod environments, and ICT-DA, CAB and business owner approvals.
    Based on idea 328505, Mechanic knowledge-base agent. Rapid AI prototype for discussion, not a council system.
